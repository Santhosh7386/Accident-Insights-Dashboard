🚦 Accident Insights Dashboard
📊 Project Overview

The Accident Insights Dashboard is a data visualization project designed to analyze road accident patterns and identify key factors that contribute to accidents. The dashboard was built using Microsoft Power BI and explores various aspects of road accidents such as accident causes, road conditions, accident severity, and time-based trends.

The goal of this project is to transform raw accident data into meaningful insights that help understand accident patterns and support better decision-making for road safety improvements.

📂 Dataset

The project uses the Global Road Accidents Dataset obtained from Kaggle.

The dataset contains information about:

Accident severity

Weather conditions

Road type

Number of vehicles involved

Time of day

Driver demographics

Accident causes

These variables allow analysis of how environmental conditions, road infrastructure, and driver behavior influence accident outcomes.

🛠 Technologies Used

Microsoft Power BI – Dashboard creation and interactive visualizations

Python – Data preprocessing and exploratory data analysis

Pandas – Data manipulation and cleaning

Matplotlib & Seaborn – Data visualization during EDA

Jupyter Notebook – Exploratory Data Analysis

📈 Dashboard Features

The Power BI dashboard includes several visualizations to analyze accident data:

KPI Cards

Displays key metrics such as:

Total Accidents

Total Casualties

Severe Accidents

Moderate Accidents

Donut Chart

Shows the distribution of accidents between Urban and Rural areas.

Line Chart

Compares current year fatalities vs previous year fatalities across months to identify trends.

Clustered Bar Chart

Analyzes accidents by road conditions such as icy, wet, dry, and snow-covered roads.

Clustered Column Chart

Compares accident counts across different road types including highways, main roads, and streets.

Monthly Accident Chart

Displays accidents by month to observe seasonal patterns.

Accident Cause Indicators

Highlights major causes of accidents including:

Distracted Driving

Drunk Driving

Mechanical Failure

Speeding

Weather

Interactive Filters

Users can filter data by:

Country

Year

Gender

The dashboard helps identify important trends such as:

Major causes of accidents (e.g., distracted driving and drunk driving)

Impact of road conditions on accident frequency

Comparison between current and previous year accident statistics

Monthly trends in accident occurrences

Differences between urban and rural accident distributions
